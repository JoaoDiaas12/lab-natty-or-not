# Fuga de Marte 🌌

## 📒 Descrição
Em "Fuga de Marte", o astronauta Brian enfrenta desafios incomparáveis em sua missão para explorar o planeta vermelho. Com a ajuda de seu leal robô, Rob16, eles enfrentam dificuldades e perigos, buscando uma maneira de retornar à Terra com segurança.

## 🤖 Tecnologias Utilizadas
- IA Generativa **[ChatGPT](https://chat.openai.com)** para roteirização;
- IA Generativa **[Leonardo AI](https://leonardo.ai)** para criar a arte visual do e-book;
- Ferramenta **Word** para edição.

## 🧐 Processo de Criação
Utilizei a ajuda do "ChatGPT" para criar a história, o modelo auxiliou na construção dos personagens, do enredo emocionante e dos desafios enfrentados pelos protagonistas, já o "Leonardo AI" foi usado para gerar imagens exclusivas do meu projeto, como a capa e imagens dentro da história e para concluir, a montagem final foi feita no Word para edição de texto.

## 🚀 Resultados
O e-book oferece um conteúdo cativante e visualmente enriquecedor, mostrando como as IA Gerativas podem ser uma ferramenta valiosa na educação e na transmissão do conhecimento.
